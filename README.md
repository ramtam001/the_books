# Bookshelf

## Назначение
Веб-приложение на Django для ведения коллекции книг: хранение информации об авторах и книгах, добавление и редактирование записей через админ-панель, просмотр списка книг и карточки отдельной книги.

## Целевая аудитория
Читатели и коллекционеры, которые хотят вести собственный каталог прочитанных или имеющихся книг.

## Предметная область
Учёт книг личной библиотеки: авторы, книги и их характеристики (жанр, дата публикации, объём, описание).

## Основные сущности
- Author (Автор)
  - name — имя автора
- Book (Книга)
  - title — название
  - author — автор (связь с Author)
  - published_date — дата публикации
  - genre — жанр
  - pages — количество страниц
  - description — описание
  - added_at — дата добавления в коллекцию

## Основные функции
- Просмотр списка всех книг
- Просмотр подробной информации о книге
- Добавление, редактирование и удаление авторов и книг через админ-панель
- Поиск и фильтрация книг в админ-панели (по названию, автору, жанру)

## Установка

```
cd bookshelf
python3 -m pip install -r requirements.txt
```

## Настройка базы данных

```
python3 manage.py makemigrations books
python3 manage.py migrate
python3 manage.py createsuperuser
```

## Запуск

```
python3 manage.py runserver
```

- Список книг: http://127.0.0.1:8000/
- Админка: http://127.0.0.1:8000/admin/

## План развития
На следующих этапах планируется:
- доработка веб-приложения (поиск и фильтры на сайте, а не только в админке);
- подключение полноценной базы данных (PostgreSQL);
- реализация пользователей (личные коллекции, авторизация);
- разработка API;
- контейнеризация приложения;
- настройка CI/CD.
